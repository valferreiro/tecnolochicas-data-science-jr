    ## 📊 Proyecto final

    ### Análisis de suicidios y violencia familiar en México

    Proyecto exploratorio basado en las Estadísticas de Defunciones Registradas 2024 del Instituto Nacional de Estadística y Geografía (INEGI).

    El análisis busca explorar las características y patrones de las defunciones por suicidio, así como las variables relacionadas con violencia familiar disponibles en la fuente.

    **Fuente de datos:**

    [INEGI - Defunciones Registradas 2024](https://www.inegi.org.mx/app/descarga/ficha.html?tit=3161201&ag=0&f=csv)

    El archivo CSV original no se incluye en este repositorio debido a su tamaño. Consulta la fuente oficial para obtenerlo.
